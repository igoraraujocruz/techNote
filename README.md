# TechNote Extension
Sistema de anotações de penalidades para auxilio dos analistas.

## Objetivo
Auxiliar no trabalho do analista de provas usando a manipulação da DOM, como por exemplo, mudar as cores dos vídeos que estão com problemas e precisam ser corrigidos, isso impede o retrabalho do analista.

É possível cadastrar as penalidades e conferir aquelas que foram cadastradas pelo preposto, diretamente no vídeo (o que aumenta muito a produtividade), o tempo da penalidade é registrado automaticamente.

## Funcionalidades
- Marcações de tempo no vídeo
- Registro de infrações por tipo
- Sugestões de comentários
- Sistema de pontuação (Apto/Inapto)
- Registro e resolução de problemas
- Atualização automática de dados
- Controle de velocidade do vídeo
- Interface draggable e persistente
